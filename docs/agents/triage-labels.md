# Triage Labels

Use these label strings for the canonical triage roles:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Waiting on reporter information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill refers to a triage role, apply the corresponding GitHub label.
